# Тёплый Ручей

Уютная фэнтезийная action-RPG с видом сверху в пиксельном стиле. Рассчитана в первую очередь на телефон и запускается в браузере.

Сейчас это прототип, этап 1.

## Что есть

- Деревня с домиками, дорожками и костром. Если герой проиграет, он вернётся к костру и потеряет четверть монет.
- Луг к востоку со слаймами: зелёные слабее, синие крепче и быстрее.
- Удар мечом с отбрасыванием врага, кувырок с неуязвимостью.
- Опыт, уровни, монеты, сердечки. На новом уровне прибавляется сердце и растёт урон.
- Звуки на Web Audio.

## Управление

| | Телефон | Компьютер |
|---|---|---|
| Ходить | джойстик (коснись левой половины экрана) | WASD / стрелки |
| Удар мечом | ⚔ | Пробел / J |
| Кувырок | ⟳ | Shift / K |
| Полный экран | ⛶ | — |

## Как запустить

Открыть `index.html` в браузере. Игра состоит из одного файла и не требует сборки и зависимостей.
