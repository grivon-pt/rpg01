# Тёплый Ручей

Уютная фэнтезийная action-RPG с видом сверху в пиксельном стиле. Рассчитана в первую очередь на телефон и запускается в браузере.

Сейчас это прототип, этап 1.

## Что есть

- Деревня с домиками, дорожками и костром. Если герой проиграет, он вернётся к костру и потеряет четверть монет.
- Луг к востоку со слаймами: зелёные слабее, синие крепче и быстрее.
- Удар мечом с отбрасыванием врага, огонёк (заклинание за ману), кувырок с неуязвимостью.
- Ролевая система S.P.E.C.I.A.L. (как в Fallout): Сила, Восприятие, Выносливость, Обаяние, Интеллект, Ловкость, Удача. Каждый параметр от 1 до 10.
- Создание героя: у всех параметров по 5 и ещё 5 свободных очков. Можно снизить один параметр ради другого или взять готовый набор: Воин, Маг, Ловкач, Душа деревни.
- За уровень даётся +1 очко S.P.E.C.I.A.L., а на каждом чётном уровне — выбор одного из трёх перков. У перков есть требования, например «Тяжёлая рука» требует S 6.
- От параметров и перков считаются здоровье, мана, урон, дальность огонька, крит, защита, скорость, кувырок, восстановление, радиус, с которого замечают слаймы, множители монет и опыта, шанс выпадения зелий.
- Сохранение в браузере: автосохранение каждые несколько секунд, на старте можно продолжить или создать нового героя.
- Опыт, уровни, монеты; из врагов выпадают сердечки (лечение) и зелья маны.
- Плавное движение: мир рисуется в полном разрешении экрана, камера двигается с точностью до доли пикселя.
- Звуки на Web Audio.

## Управление

| | Телефон | Компьютер |
|---|---|---|
| Ходить | джойстик (коснись левой половины экрана) | WASD / стрелки |
| Удар мечом | ⚔ | Пробел / J |
| Огонёк | ✦ | E / L |
| Кувырок | ⟳ | Shift / K |
| Экран героя и перки | 👤 | C |
| Полный экран | ⛶ | — |

## Как запустить

Открыть `index.html` в браузере. Игра состоит из одного файла и не требует сборки и зависимостей.
